UGC Skills Setup Guide

Clone the UGC video-production skills into your own Claude Code and start making hyper-realistic avatar ads. This guide takes you from zero to your first rendered video.
github.com/kofiowusuai-lab/ugc-skills   ·   Public repo  ·  MIT license  ·  ~15 minutes to set up

What you are installing

Five Claude Code skills plus the full generation engine behind them. Once installed, you invoke a skill by name (/ugc-video-producer) or just ask Claude in plain language.

ugc-video-producer
The main pipeline. End-to-end talking-head spokesperson video: character, image-to-video, voice, lip-sync. Hand it a product and it writes the script first.
ugc-ad-strategist
The brain for the words. Researches the audience, mines winning ads, picks one claim, writes the hooks and beat sheet.
ugc-device-screen
Puts real, razor-sharp content on a phone or laptop screen inside the scene using real pixels, not generated text.
ugc-minimax-mode
The full pipeline adapted for a blind, text-only model. Claude handles the shot planning and vision QA.
ugc-vision-referee
Deprecated helper, folded into minimax-mode. Kept for reference.

Before you start: the checklist

Install these first. The skills call each one, so the pipeline needs them present.

Accounts & tools

  • A GitHub account (free) to view and clone the repo
  • Claude Code installed and signed in
  • Git on your machine
  • Python 3.9+ and Node.js 18+

Command-line tools

  • grok — xAI Grok CLI (image + video)
  • gemini — Google Gemini CLI (vision QA)
  • ffmpeg + ffprobe (video)
  • rubberband (audio time-stretch)

API keys you will need

KeyUsed forRequired?
ELEVENLABS_API_KEYVoice generation and voice swapYes
GEMINI_API_KEYVision QA, rejecting off-model clipsYes
WAVESPEED_API_KEYLip-sync re-animationOptional
Heads up: Grok, ElevenLabs, Gemini and WaveSpeed all bill per use. Start with short test clips before you run a batch.
1

Find the repository

Open the repo in your browser to see the code, the README, and the file layout:

https://github.com/kofiowusuai-lab/ugc-skills

The repo is public, so you do not need an invite. You can read every file directly on GitHub before you clone. Click the green Code button to see the clone URL, or just copy the command in the next step.

2

Clone it to your machine

Open a terminal, move into the folder where you keep projects, and clone:

# move to wherever you want the project to live
cd ~/projects

# clone over HTTPS (works for everyone)
git clone https://github.com/kofiowusuai-lab/ugc-skills.git

cd ugc-skills

If you have the GitHub CLI, gh repo clone kofiowusuai-lab/ugc-skills does the same thing.

3

Run the installer

One script copies the skills where Claude Code looks for them, installs the engine scripts, and drops the voice package in place. It backs up anything it would overwrite.

bash install.sh

It installs to three locations:

WhatGoes to
The five skills~/.claude/skills/
The engine scripts~/.openclaw/scripts/
The voice package~/voiceswap/
4

Add your API keys

Copy the template, fill in your keys, then load it into your shell:

# create your private key file from the template
cp .env.example .env

# open .env in any editor and paste your keys, then:
set -a; . ./.env; set +a
Your keys stay private. The .env file is already listed in .gitignore, so it never gets committed or pushed. Run the set -a line once in each new terminal session before you use the skills.
5

Install the Python dependencies

python3 -m pip install -r requirements.txt

This installs elevenlabs, opencv, numpy, scipy, Pillow and requests. Captions and revoice mode also want openai-whisper, which you can add later if you need them.

6

Verify Claude Code sees the skills

Open Claude Code in any folder and type /. You should see the ugc- skills in the list. Or just ask:

you › make a UGC ad for a $27 ebook about meal prep

Claude picks up ugc-video-producer, runs the strategist to write the script, then generates the video. If the skills do not appear, restart Claude Code so it re-scans ~/.claude/skills/.

7

Make your first video

Start small to keep costs low. A single short clip proves your keys and tools all work:

you › make a 6-second UGC talking-head clip:
        a woman in a kitchen saying "honestly this
        changed how I meal prep" — use the brittney voice

From there you can ask for full ads, multi-clip videos, a product on a device screen, or a specific spokesperson. The skills handle the pipeline; you describe what you want.

Keeping your copy up to date

When the repo gets new skills or fixes, pull the changes and re-run the installer:

cd ~/projects/ugc-skills
git pull
bash install.sh

Troubleshooting

SymptomFix
Skills do not show up in Claude CodeRestart Claude Code. Confirm the folders exist under ~/.claude/skills/ugc-*.
ELEVENLABS_API_KEY not foundYou did not load .env in this terminal. Run set -a; . ./.env; set +a again.
grok: command not found or same for geminiThe CLI is not on your PATH. Install it and reopen the terminal.
ffmpeg / rubberband missingmacOS: brew install ffmpeg rubberband. Linux: apt install ffmpeg rubberband-cli.
A generated clip drifts off the characterExpected sometimes. The vision QA step rejects bad takes and retries. Let it finish.
Voice sounds wrong or has an accentUse speech-to-speech, not text-to-speech. To use your own cloned voice: export UGC_MY_VOICE="me=your_voice_id" then ask for the me voice.
Note on motion graphics: the optional captions and text-behind-avatar polish needs a separate render project that is not included. The pipeline notices it is missing and delivers the plain cut, so you can ignore the --studio and --broll flags.
